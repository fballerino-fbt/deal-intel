SECTION 3: STEP-BY-STEP PRODUCTION LAUNCH MAP
Create a Private GitHub Repository: Log into GitHub and open a fresh, private repository named deal-intel.
Commit Code Assets: Upload the exact text files for config.json, cell_deal_intel.py, and send_alert.py directly to the repository root.
Commit the Workflow Blueprint: Create a folder directory path inside your project called .github/workflows/ and upload your daily_cron.yml file into that space.
Input Encrypted Secrets: Navigate to repository Settings > Secrets and variables > Actions > New repository secret, and save your four API environment keys:
GROQ_API_KEY: Paste your free Groq Cloud API inference key.
SENDER_EMAIL: The Google email account address sending out alerts.
GMAIL_APP_PASSWORD: The 16-character Google App Password (found in Google Account Security settings).
MANAGER_EMAIL: The target recipient address where store managers open notifications.
Turn On Web Hosting: Open repository Settings > Pages. Change Build and deployment > Source to "Deploy from a branch", choose gh-pages in the branch selection, and save the settings.
Force Launch: Click your repository's Actions tab, select your pipeline from the list, click Run workflow, and your tracking dashboard is live!
